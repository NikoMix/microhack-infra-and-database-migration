---
title: Glossary
---

| Term | Meaning |
| --- | --- |
| ACR | Advanced Specialization capability review evidence and controls. |
| Azure Migrate | Microsoft service for discovering, assessing, planning, and executing migrations. |
| AVM | Azure Verified Modules, reusable Microsoft-aligned IaC modules. |
| Azure-SSIS IR | Data Factory Integration Runtime that runs SSIS packages in Azure. |
| Elastic Jobs | Azure SQL Database job automation for scheduled or fan-out T-SQL tasks. |
| MCP | Model Context Protocol, a way to provide tools and context to AI agents. |
| Rehost | Move a workload to infrastructure with minimal application change. |
| T-14/T-0/T+14 | Runbook phases before, during, and after cutover. |
