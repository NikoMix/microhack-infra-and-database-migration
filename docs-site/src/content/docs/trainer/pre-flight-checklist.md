---
title: Pre-flight checklist
---

## T-7 days

- Confirm subscriptions, quotas, policy constraints, and allowed regions.
- Pre-provision SQL Managed Instance and any shared Azure-SSIS IR demos.
- Validate GitHub access, Codespaces availability, and Copilot licensing.
- Review Microsoft Learn updates for Azure Migrate, MSSQL extension, Flexible Servers, Defender for Cloud, Backup, Arc, and Azure Verified Modules.

## T-1 day

- Run a clean source estate deployment.
- Build the documentation site and render the Marp deck.
- Test `mcopilot assess`, `architect`, `convert`, `runbook`, and `evidence`.
- Export screenshots or text evidence for slow operations.
- Prepare breakout room assignments and support contacts.

## T-0 morning

- Open the Azure portal, GitHub repo, slide deck, and timer.
- Confirm no unexpected Azure service health issues affect the chosen region.
- Start shared demo resources only when needed.
- Remind attendees to stop or tear down resources before leaving.
